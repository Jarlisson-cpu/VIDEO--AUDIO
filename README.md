# 🎬 Vídeo e Áudio com HTML5

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)

Estudo de **multimídia no HTML5**: incorporação de vídeo do YouTube com `<iframe>` e player de áudio com a tag `<audio controls>`.

## 🚀 Como executar

Abra `HMTL-5/index.html` no navegador.

> Para o áudio tocar, troque `caminho-para-o-seu-arquivo.mp3` por um arquivo `.mp3` real.
